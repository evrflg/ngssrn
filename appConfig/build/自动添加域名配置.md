# 自动域名配置功能使用指南

### 基本用法

```bash
# 使用默认域名
sh appConfig/build/build-ios-with-domain.sh

# 使用自定义域名
sh appConfig/build/build-ios-with-domain.sh --domain https://api.yourdomain.com

# 清理并重新生成域名配置
sh appConfig/build/build-ios-with-domain.sh --domain https://api.yourdomain.com --clean
```

## 故障排除

### 如果域名模块不工作：

1. **Android 问题**:

   - 检查 `DomainModule.java` 是否已正确添加 `DOMAIN_URL`
   - 检查 `MainApplication.kt` 是否已正确添加 `ConfigPackage`
   - 查看 `com.yunji.app.v3.config` 包下是否存在必要文件
   - 确认 `ConfigModule.java` 的 `getName()` 返回值为 "DomainModule"

2. **iOS 问题**:

   - 检查 `Info.plist` 中是否存在 `domain_url` 键
   - 确认 `DomainModule.m` 是否已添加到 Xcode 项目中
   - 查看 Xcode 是否正确引用了该模块

3. **通用解决方案**:
   - 使用 `--clean` 参数重新运行脚本
   - 检查 JavaScript 代码中是否正确引用了 `NativeModules.DomainModule`
   - 确保在 React Native 初始化完成后再访问域名
